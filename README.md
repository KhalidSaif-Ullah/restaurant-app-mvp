# Restaurant App MVP

A frontend-only React Native restaurant application developed for Assignment No. 1, Fall 2026.

## Technologies

* React Native
* Expo
* JavaScript / TypeScript
* React Hooks
* AsyncStorage

## Requirements

* Node.js
* npm
* Expo Go

## Installation

```bash
npm install
npx expo start
```

Open the application using Expo Go on a mobile device.

## Implemented Features

* Login and signup
* Menu browsing
* Category filtering and sorting
* Search with debounce
* Favourites
* Dark/light theme
* Global authentication context
* Shopping cart
* Quantity management and item notes
* Promo codes
* Order placement
* Order tracking with status progression
* Reservation system
* AsyncStorage persistence
* Manager dashboard
* Order management
* Reservation management
* Menu availability management
